Most design systems are written for people and then scraped by AI tools. Atomus is written for both. Every rule a designer or developer reads on this site is also published in a form agents can follow literally. The props, tokens and rules agents use are **generated from the same sources** as the Figma file and the React package, so they can't drift.

The result: Claude Code, Cursor, Copilot, Figma Make and the Figma MCP server pick the right component, use only real props, style with semantic tokens and keep one primary action per view. You review the result instead of fixing it.
