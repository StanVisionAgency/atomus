## Usage

```tsx
import { Sources, InlineCitation } from '@stanvision/atomus-react';

<p>Body text needs a contrast of at least 4.5:1 <InlineCitation index={1} source={sources[0]} />.</p>
<Sources sources={sources} />
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `SourceItem` — `id`, `title`, `url`, `domain` (derived from `url`), `snippet`, `icon`.
- `Sources` — `variant` `collapsible` (default) or `list`; `label` overrides "N sources".
- `InlineCitation` — `index` matches the position in `sources`.
