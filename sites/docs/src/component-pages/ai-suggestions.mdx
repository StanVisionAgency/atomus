## Usage

```tsx
import { Suggestions } from '@stanvision/atomus-react';

<Suggestions suggestions={['Fix the contrast issue', 'Show the axe report']} onSelect={send} />
<Suggestions mode="insert" suggestions={['Make it shorter']} onSelect={(p) => setDraft(p)} />
<Suggestions variant="cards" suggestions={starters} onSelect={send} />
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `suggestions` — strings or `{ label, prompt, description, icon }`.
- `mode` — `send` (arrow) or `insert` (plus); `onSelect(prompt, item)`.
- `variant` — `chips` or `cards`; `wrap` lets chips wrap instead of scroll.
