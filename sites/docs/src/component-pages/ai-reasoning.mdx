## Usage

```tsx
import { Reasoning } from '@stanvision/atomus-react';

<Reasoning
  status={thinking ? 'thinking' : 'done'}
  duration={seconds}
  steps={[
    { label: 'Load the page', status: 'done' },
    { label: 'Run axe-core', detail: '68 rules', status: 'active' },
    { label: 'Draft fixes', status: 'pending' },
  ]}
>
  <p>{summary}</p>
</Reasoning>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `status` — `thinking` or `done`; `duration` in seconds for "Thought for 12s".
- `steps` — `label`, `detail` and `status` (`pending` · `active` · `done`); `children` for free text.
- `open` / `defaultOpen` / `onOpenChange`; `autoCollapse` closes it when thinking ends.
