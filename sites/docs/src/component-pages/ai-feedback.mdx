## Usage

```tsx
import { Feedback } from '@stanvision/atomus-react';

<Feedback
  onChange={(rating) => track('rating', rating)}
  onSubmit={({ rating, reasons, comment }) => sendFeedback(messageId, rating, reasons, comment)}
/>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `value` / `defaultValue` / `onChange` — `'up'`, `'down'` or `null`.
- `reasons` for a thumbs down (defaults provided); `positiveReasons` opens a form for a thumbs up too.
- `onSubmit` receives `{ rating, reasons, comment }`.
