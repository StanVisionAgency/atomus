## Usage

```tsx
import { ToolCall } from '@stanvision/atomus-react';

<ToolCall
  name="search_docs"
  title="Searched the docs"
  status="success"            // 'pending' | 'running' | 'success' | 'error'
  duration={420}
  input={{ query: 'card border token' }}
  output={{ results: 3 }}
/>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `name` (monospace) and `title` (plain language); `icon` for the integration's logo.
- `status` with an icon and a word; `duration` in ms.
- `input` and `output` — strings or objects (formatted as JSON); `error` replaces the output.
- `open` / `defaultOpen` / `onOpenChange` for the disclosure.
