## Usage

```tsx
import { PromptInput, ModelSelector, ContextMeter } from '@stanvision/atomus-react';

<PromptInput
  status={status}                       // 'ready' | 'submitted' | 'streaming' | 'error'
  onSubmit={(text, files) => send(text, files)}
  onStop={stop}
  attachments={files}
  onAttach={openFilePicker}
  onRemoveAttachment={removeFile}
  toolbar={<ModelSelector models={models} value={model} onChange={setModel} />}
  actions={<ContextMeter used={usage.tokens} limit={200000} />}
  triggers={[{ char: '/', items: commands }, { char: '@', label: 'People', items: people }]}
  disclaimer="AI can make mistakes. Check important information."
/>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `status` — `submitted` and `streaming` show Stop and block Enter; the text area stays editable.
- `value` / `defaultValue` / `onChange` — controlled or uncontrolled text; `onSubmit` gets the trimmed text and the attachments.
- `attachments`, `onAttach`, `onRemoveAttachment` — chips with an upload state; an uploading file blocks Send.
- `toolbar` and `actions` — slots on the left and right of the bottom bar.
- `triggers` — `/` and `@` menus with keyboard support (↑ ↓, Enter or Tab, Esc).
- `size` — `md` for panels, `lg` for full-page chat. `minRows` / `maxRows` set the growth.
