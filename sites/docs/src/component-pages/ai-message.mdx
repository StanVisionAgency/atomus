## Usage

```tsx
import { Message, StreamingText, Feedback } from '@stanvision/atomus-react';

<Message role="user" name="Kristina" copyText={prompt} onEdit={edit}>
  <p>{prompt}</p>
</Message>
<Message
  role="assistant"
  name="Atomus Assistant"
  status={status}                        // 'streaming' | 'done' | 'error' | 'stopped'
  copyText={answer}
  onRegenerate={regenerate}
  branch={{ index: 2, count: 3, onPrevious, onNext }}
  actions={<Feedback onSubmit={sendFeedback} />}
>
  <StreamingText text={answer} streaming={status === 'streaming'} />
</Message>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `role` — `user` · `assistant` · `system` · `tool`; `name` is always announced (Primer: speaker clarity).
- `status` — `streaming` hides the actions and sets `aria-busy`; `error` shows the message with Retry (`onRegenerate`); `stopped` notes that the person stopped it.
- Actions: `copyText` (Copy), `onRegenerate`, `onEdit`, `branch`, and the `actions` slot. `actionsVisibility="hover"` for dense threads.
- `avatar`, `showName`, `aiLabel`, `time` and `dateTime` for the header.
