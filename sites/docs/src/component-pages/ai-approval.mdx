## Usage

```tsx
import { Approval } from '@stanvision/atomus-react';

<Approval
  title="Send this summary to #design-system?"
  risk="medium"
  toolName="slack.post_message"
  editableText={draft}
  alwaysAllowLabel="Always allow posting to #design-system"
  status={decision}                               // 'pending' | 'approved' | 'denied'
  onApprove={({ alwaysAllow, editedText }) => run(editedText ?? draft, alwaysAllow)}
  onDeny={cancel}
>
  The assistant will post one message as you.
</Approval>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `title` (the question), `children` (summary), `risk` (`low` · `medium` · `high`), `toolName`.
- `details` for a read-only preview, or `editableText` for edit-then-approve; `onApprove` receives `{ alwaysAllow, editedText }`.
- `alwaysAllowLabel` shows the checkbox — never for high risk.
- `status` keeps the outcome visible after the decision; `approveLabel` names the action ("Delete variables").
