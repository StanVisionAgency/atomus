## Usage

```tsx
import { EmptyState } from '@stanvision/atomus-react';

<EmptyState
  title="No projects yet"
  description="Create your first project to start designing with Atomus."
  actions={<Button hierarchy="primary">New project</Button>}
/>
```

Fills an empty page, table or panel and says what to do next.

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `title` (what's missing), `description` (one sentence), `actions`, `icon`, `size` `sm` (panels) · `md` (pages).
