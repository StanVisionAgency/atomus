`StreamingText` renders a reply as it arrives, with a gradient caret, and tells screen readers about finished sentences in batches instead of every token. `Shimmer` sweeps a soft light across short status lines. Both stop moving when the person prefers reduced motion.

## Usage

```tsx
import { StreamingText, Shimmer } from '@stanvision/atomus-react';

// Pass the whole string received so far on every chunk.
<StreamingText text={text} streaming={!done} render={(t) => <Markdown>{t}</Markdown>} />

// Long code or tables: only say when it's done.
<StreamingText text={code} streaming={!done} announce="end" doneMessage="Code ready" />

<Shimmer>Searching 12 sources…</Shimmer>
```

### Motion tokens

- `--motion-stream-caret-blink` (1s) and `--motion-stream-shimmer-duration` (1.8s). Both become `0s` under `prefers-reduced-motion: reduce`, and the components switch their animation off.
