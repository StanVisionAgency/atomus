Shows how full the model's context window is and what the conversation cost. The compact ring sits in the Prompt input; click it for the breakdown. It turns warning at 80% and error at 95%, with a sentence that says what happens next.

## Usage

```tsx
import { ContextMeter } from '@stanvision/atomus-react';

<ContextMeter
  used={usage.totalTokens}
  limit={200000}
  cost={usage.costUsd}
  breakdown={[{ label: 'Input', tokens: usage.input }, { label: 'Output', tokens: usage.output }]}
/>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `used`, `limit` (tokens), `cost` and `currency`, `breakdown`.
- `variant` — `compact` (ring + %, details on click) or `bar`.
- `warnAt` (80) sets the warning threshold; error is fixed at 95%. `locale` formats numbers.
