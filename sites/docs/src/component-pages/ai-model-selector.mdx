## Usage

```tsx
import { ModelSelector } from '@stanvision/atomus-react';

<ModelSelector
  models={[
    { value: 'pro', label: 'Atomus Pro', provider: 'StanVision', icon: <Logo />, description: 'Best for long, careful work', capabilities: ['Reasoning', 'Tools', 'Vision'], badge: 'New' },
    { value: 'fast', label: 'Atomus Fast', provider: 'StanVision', capabilities: ['Fast'] },
  ]}
  value={model}
  onChange={setModel}
/>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `models` — `value`, `label`, `provider`, `icon`, `description`, `capabilities`, `badge`, `disabled`.
- `variant` — `ghost` (toolbar) or `outline` (settings); `size` `sm` or `md`; `placement` `up` (default) or `down`.
- `label` names the combobox; `showLabel` shows it above the trigger.
