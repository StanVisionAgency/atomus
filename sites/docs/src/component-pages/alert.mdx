## Usage

```tsx
import { Alert } from '@stanvision/atomus-react';

<Alert color="warning" title="Trial ends in 3 days" onClose={dismiss}>
  Add a payment method to keep your projects.
</Alert>
```

### Props at a glance

Full types and defaults are in [React API](#react-api) at the end of the page.

- `color` — `brand` · `gray` · `error` · `warning` · `success` (aliases: `info` → brand, `neutral` → gray, `danger` → error).
- `variant` — `subtle` (default, tinted) · `outline` (white, for tinted or grey surfaces) · `solid` (blocking issues only). Figma: Style.
- `size` — `md` (default) or `sm` for dense UI; `flush` removes the radius and side borders for full-bleed placement.
- `title` and `children` (Figma: Title, Description); `actions` — up to two small buttons; `onClose` (Figma: Close).
- Each colour has its own icon, so meaning never depends on colour alone. Colours come from the `--color-alert-*` component tokens.

**Don’t**

- Don't stack more than two alerts; use toasts for transient confirmations.
- Don't use `solid` for routine messages.
