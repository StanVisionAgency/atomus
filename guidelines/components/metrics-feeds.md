# Metrics & feeds

## Metric card

KPI / stat card for dashboards and marketing.

Variants: 3

| Property | Type / options |
|---|---|
| Label | text |
| Value | text |
| Type | Simple · Trend · Chart |

**Do**

- Lead with the number.
- Use Trend to show change against a stated period.
- Keep units in the value (“$48.2k”, “12%”).

**Forbidden**

- Never show more than four metric cards in a row.
- Never mix time periods in one row.
- Never colour-code a change without the arrow.

## Banner

Full-width announcement bar.

Variants: 2

| Property | Type / options |
|---|---|
| Title | text |
| Message | text |
| Action | boolean (on) |
| Color | Default · Brand |

**Do**

- Use for one product- or account-wide message at the top of the page, and let people dismiss it.

**Forbidden**

- Never show more than one banner at a time.
- Never use a banner for form or section errors — use Alert.
