# Metrics & feeds

## Metric card

KPI / stat card for dashboards and marketing.

Variants: 3

| Property | Type / options |
|---|---|
| Label | text |
| Value | text |
| Type | Simple · Trend · Chart |

**Do**

- Lead with the number.
- Use Trend to show change vs a period.
- Keep units in the value.

**Don’t**

- Don’t show more than four in a row.
- Don’t mix time periods.
- Don’t colour-code without the arrow.
