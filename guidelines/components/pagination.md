## Pagination

Pagination bar for tables and lists.

Variants: 2

| Property | Type / options |
|---|---|
| Type | Page numbers · Minimal |

**Do**

- Show the current page and total.
- Keep Previous / Next visible.
- Use for tables over ~25 rows.

**Don’t**

- Don’t use for feeds.
- Don’t show more than seven numbers.
- Don’t reset the page on sorting.
