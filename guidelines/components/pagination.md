## Pagination

Pagination bar for tables and lists.

Variants: 2

| Property | Type / options |
|---|---|
| Type | Page numbers · Minimal |

**Do**

- Show the current page and the total.
- Keep Previous and Next visible.
- Use for tables over about 25 rows.

**Forbidden**

- Never paginate feeds — load more instead.
- Never show more than seven page numbers.
- Never reset the page when sorting.
