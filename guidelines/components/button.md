# Button

## Button

Hierarchy: Primary (main action, one per view), Secondary, Outline, Tertiary (low emphasis), Link. Sizes xs–xl (24–56px). Icons via instance swap. Loading shows a spinner.

Variants: 125

| Property | Type / options |
|---|---|
| Label | text |
| Leading icon | boolean (off) |
| Leading icon swap | instance swap (icon) |
| Trailing icon | boolean (off) |
| Trailing icon swap | instance swap (icon) |
| Hierarchy | Primary · Secondary · Outline · Tertiary · Link |
| Size | xs · sm · md · lg · xl |
| State | Default · Hover · Focused · Disabled · Loading |

**Do**

- Use one primary button per view, for the main action.
- Label with a verb in sentence case: “Save changes”, not “OK”.
- Match sizes in a row — buttons and inputs share the 32 / 40 / 48 heights.
- Put the primary action last in a group, after Cancel.

**Forbidden**

- Never put two primary buttons in one view.
- Never use the Link style for destructive actions.
- Never detach to change an icon — use Leading / Trailing icon swap.
- Never use a button to navigate to another page — use a link.

## Button icon

Icon-only button. Same hierarchies, sizes and states as Button; square 24–56px. Always give it a tooltip or aria-label in code.

Variants: 100

| Property | Type / options |
|---|---|
| Icon | instance swap (icon) |
| Hierarchy | Primary · Secondary · Outline · Tertiary |
| Size | xs · sm · md · lg · xl |
| State | Default · Hover · Focused · Disabled · Loading |

**Do**

- Always give it an accessible name (`aria-label`) and a tooltip.
- Use Tertiary in toolbars, cards and table rows.

**Forbidden**

- Never use an icon-only button for the main action of a view.
- Never use an icon whose meaning is not widely understood without a label.
