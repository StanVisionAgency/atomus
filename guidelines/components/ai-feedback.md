# AI: Feedback

## Feedback

Thumbs up / down on an AI reply. A thumbs down (and, optionally, a thumbs up) opens a short form in place: reason chips, an optional comment and Send feedback. After sending, a quiet "Thanks for your feedback" replaces the form. Part of the Agent kit.

Figma: component set `Feedback` on the 🤖 Agent kit page of Atomus 4.0 (node `25545:219`), connected to React with Code Connect. React props use the same names as the Figma properties below.

| Property | Type / options |
|---|---|
| Rating | None · Up · Down |
| Reasons | list (text) |
| Size | xs · sm |
| Form | boolean (opens after a rating) |

**Use for**

- The actions row of an assistant Message.
- Rating a generated draft, summary or image.

**Not for**

- Product surveys or NPS: use a form or Modal.

**Accessibility**

- Thumbs are toggle buttons (`aria-pressed`) named "Good response" and "Bad response".
- The form opens because the person asked for it, so focus moves to its first reason; Esc closes it.
- Reason chips are toggle buttons; the confirmation is announced in a status region.

**Do**

- Keep reasons short and specific: "Not accurate", "Too long", "Didn't follow instructions".
- Make the comment optional and send the rating even when the form is closed.

**Forbidden**

- Never require a reason or a comment.
- Never open the form for a thumbs up unless you offer positive reasons.
