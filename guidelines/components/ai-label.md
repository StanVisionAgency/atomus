# AI: AI label

## AI label

Marks AI-generated content and is the entry point to explainability: a pill with the gradient AI mark and a short word ("AI", "AI generated"). With an explanation it becomes a button that opens a popover: why the person sees this, which model made it, and — once they edited the content — "Revert to AI". Part of the Agent kit.

Figma: planned component. The properties below are the Figma properties to come; React props already use the same names.

| Property | Type / options |
|---|---|
| Label | text ("AI") |
| Size | xs 20 · sm 24 · md 28 |
| Style | Chip · Inline · Icon |
| Explainability popover | boolean + content |
| Model | text |
| Edited | boolean (off) |
| Revert to AI | boolean (on when Edited) |

**Anatomy**

1. AI mark: a sparkle filled with `--gradient-ai`.
2. Label in `text-ai` on `bg-ai-subtle` with a `border-ai` hairline.
3. Chevron when it opens a popover.
4. Popover: gradient top edge, title, explanation, footer with the model and "Revert to AI".

**Edited**

When a person changes AI content, the label reads "Edited", loses the AI tint and shows a pencil. The popover keeps the explanation and offers "Revert to AI", which restores the generated content.

**Use for**

- Next to anything an AI wrote or changed: messages, summaries, generated fields, table cells, images.
- Field labels of inputs that an AI prefilled.

**Not for**

- Marketing badges ("New", "Pro"): use Badge.
- Decoration — the AI tint and gradient only identify AI content.

**Accessibility**

- The `icon` style keeps the label as visually hidden text.
- With a popover, the label is a button with `aria-expanded`; the popover is a non-modal dialog named by its title. Esc and an outside click close it and return focus.
- AI content is never marked by colour or gradient alone — the word stays.

**Do**

- Label every piece of AI-generated content in the same way across the product.
- Say in the explanation where the content came from and what to check.
- Offer "Revert to AI" whenever people can edit generated content.

**Forbidden**

- Never use `--gradient-ai`, `bg-ai-subtle` or `border-ai` on content that is not AI.
- Never hide the label once the person has edited the content — switch it to Edited.
- Never put actions other than Revert to AI and links to settings in the popover.
