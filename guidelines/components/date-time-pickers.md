## Date picker

Calendar dropdown: single date or range.

Variants: 2

| Property | Type / options |
|---|---|
| Type | Single · Range |

**Do**

- Show today and the selected range clearly.
- Allow typing the date in Date input.
- Offer presets for common ranges.

**Don’t**

- Don’t hide the year when ranges cross years.
- Don’t disable past dates unless required.
- Don’t use for birth dates — use Date input.
