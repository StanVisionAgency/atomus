# AI: Context meter

## Context meter

How much of the model's context window a conversation uses, and what it has cost. The compact style is a ring and percentage for the Prompt input; it opens a card with the bar, a breakdown (input, output, tools) and the cost. The bar style shows the same details inline. Part of the Agent kit.

Figma: planned component. The properties below are the Figma properties to come; React props already use the same names.

| Property | Type / options |
|---|---|
| Used | number (tokens) |
| Limit | number (tokens) |
| Cost | number + currency |
| Breakdown | list (label, tokens) |
| Style | Compact · Bar |
| State | Default · Warning (80%) · Error (95%) |

**State**

- Below `warnAt` (80%) the fill uses `--gradient-ai`.
- From 80% it turns `fg-warning` with "Getting full: start a new chat for a new topic."
- From 95% it turns `fg-error` with "Almost full: older messages will be summarised or dropped."

**Use for**

- Power-user and developer tools where people manage long conversations or pay per token.

**Not for**

- Consumer chat where tokens mean nothing to people — explain limits in words instead.
- Upload or task progress: use Progress bar.

**Accessibility**

- The bar is a WAI-ARIA `meter` with a text value: "24% used, 48.2K of 200K tokens".
- The compact trigger is a button named with the same text; its card closes with Esc.
- Warning and error states add a sentence, not only a colour.

**Do**

- Format large numbers compactly (48.2K) and show cost in the person's currency.
- Explain what happens when the window is full.

**Forbidden**

- Never block sending when the meter is full without saying why and what to do.
