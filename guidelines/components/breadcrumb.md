# Breadcrumb

## Breadcrumb item

Breadcrumb segment: Home (icon), Link, Current.

Variants: 5

| Property | Type / options |
|---|---|
| Label | text |
| Type | Home · Link · Current |
| State | Default · Hover |

## Breadcrumb

Breadcrumb trail; last segment is Current.

Variants: 2

| Property | Type / options |
|---|---|
| Separator | Chevron · Slash |

**Do**

- Show the full path from the top level.
- Make every item except the last a link.
- Collapse middle items with “…” when long.

**Don’t**

- Don’t use on single-level apps.
- Don’t repeat the page title in the same row.
- Don’t wrap to two lines.
