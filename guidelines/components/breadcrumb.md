## Breadcrumb

Breadcrumb trail; last segment is Current.

Variants: 2

| Property | Type / options |
|---|---|
| Separator | Chevron · Slash |

**Do**

- Show the full path from the top level.
- Make every item except the last a link; the last item is the current page.
- Collapse middle items into “…” when the path is long.

**Forbidden**

- Never use breadcrumbs in single-level apps.
- Never repeat the page title in the same row.
- Never let a breadcrumb wrap to two lines.
