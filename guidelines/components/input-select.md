# Input & Select

## Input

Text input. Label position Outside, Inside (floating) or Notched. Sizes 32/40/48 match Buttons.

Variants: 42

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Hint | text |
| Show hint | boolean (on) |
| Label position | Outside · Inside · Notched |
| Size | sm · md · lg |
| State | Default · Hover · Focused · Filled · Disabled · Error |

**Do**

- Always show a label; use Inside or Notched when space is tight.
- Use the hint for format help and Error for validation.
- Match the size to the buttons in the same form.

**Forbidden**

- Never use placeholder text as the label.
- Never show an error before the user has typed.
- Never clear the user's value after an error.

## Select

Select trigger; pair with Dropdown menu for the open list.

Variants: 15

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Show hint | boolean (on) |
| Size | sm · md · lg |
| State | Default · Focused · Filled · Disabled · Error |

**Do**

- Use for one choice from six or more options, or when space is tight.
- Write a placeholder that says what to pick (“Select a country”).

**Forbidden**

- Never use Select for two to four options — use Radio or a segmented Tabs.
- Never put actions in the option list — use Dropdown menu.

**Do**

- Show the selected values as tags in the field.

**Forbidden**

- Never use Multi-select when only one value is allowed — use Select.
