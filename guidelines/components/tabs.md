# Tabs

## Tab

Single tab: Underline, Pill or Segmented.

Variants: 30

| Property | Type / options |
|---|---|
| Label | text |
| Icon | boolean (off) |
| Icon swap | instance swap (icon) |
| Count | boolean (off) |
| Count number | text |
| Style | Underline · Pill · Segmented |
| Size | sm · md |
| State | Default · Hover · Active · Focused · Disabled |

## Tabs

Tab bar built from Tab.

Variants: 3

| Property | Type / options |
|---|---|
| Style | Underline · Pill · Segmented |

**Do**

- Use for views of the same content.
- Keep labels short; add counts when they help.
- Use Vertical tabs for settings.

**Forbidden**

- Never use tabs for sequential steps — use Progress steps.
- Never exceed seven tabs.
- Never mix tab styles on one page.

## Vertical tabs

Side navigation for settings and long forms.

Variants: 2

| Property | Type / options |
|---|---|
| Style | Line · Pill |
