# Empty state & file upload

## Empty state

Empty / no-results state for tables, lists and pages.

Variants: 2

| Property | Type / options |
|---|---|
| Title | text |
| Description | text |
| Actions | boolean (on) |
| Size | sm · md |

**Do**

- Explain what will appear and how to start.
- Offer one primary action.
- Use md inside cards and pages.

**Don’t**

- Don’t leave a screen blank.
- Don’t blame the user.
- Don’t show more than two actions.
