# Empty state & file upload

## Empty state

Empty / no-results state for tables, lists and pages.

Variants: 2

| Property | Type / options |
|---|---|
| Title | text |
| Description | text |
| Actions | boolean (on) |
| Size | sm · md |

**Do**

- Explain what will appear here and how to start.
- Offer one primary action.
- Use md in pages and cards, sm in narrow panels.

**Forbidden**

- Never leave a screen blank.
- Never blame the user.
- Never show more than two actions.

## File upload

Drop zone. Hover = dragging a file over it.

Variants: 3

| Property | Type / options |
|---|---|
| Hint | text |
| State | Default · Hover · Disabled |

**Do**

- State the accepted file types and the size limit.
- Show progress and a clear error per file (File upload item).

**Forbidden**

- Never upload silently without showing the file list.

## File upload item

Uploaded file row with progress.

Variants: 3

| Property | Type / options |
|---|---|
| File name | text |
| State | Uploading · Complete · Error |
