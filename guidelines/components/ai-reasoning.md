# AI: Reasoning

## Reasoning

A collapsible disclosure for the model's working: "Thinking…" with a shimmer while it reasons, then "Thought for 12s". Inside, a short step list and optional free text, on a left rule in `border-ai`. It keeps the model's working apart from its answer. Part of the Agent kit.

Figma: component set `Reasoning` on the 🤖 Agent kit page of Atomus 4.0 (node `25548:978`), connected to React with Code Connect. Steps: `Reasoning step` (node `25548:901`). React props use the same names as the Figma properties below.

| Property | Type / options |
|---|---|
| State | Thinking · Done |
| Duration | number (seconds) |
| Steps | list (label, detail, status: Pending · Active · Done) |
| Expanded | boolean |
| Label | text |

**Anatomy**

1. Trigger: lightbulb in `text-ai`, label ("Thinking…" shimmer or "Thought for 12s"), chevron.
2. Body: steps with status dots (gradient for active, `text-ai` for done, outline for pending), then free text.

**Use for**

- Showing what a reasoning model or agent did before answering.
- Multi-step plans the agent is working through.

**Not for**

- Function calls with inputs and outputs: use Tool call.
- The answer itself: put it in the Message content.

**Accessibility**

- The trigger is a button with `aria-expanded` and `aria-controls`.
- The finished label ("Thought for 12s") is announced once in a status region.
- Step status is also given as text ("in progress", "pending"), not only by the dot.

**Do**

- Open it while thinking and collapse it when done (`autoCollapse`, the default).
- Write steps as short past-tense or present-tense lines a person can scan.
- Summarise long raw thoughts; show the full text only on request.

**Forbidden**

- Never put the answer or required decisions inside Reasoning — people may never open it.
- Never show a duration for a step that is still running.
