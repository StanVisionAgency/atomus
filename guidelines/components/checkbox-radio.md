# Checkbox & Radio

## Checkbox

Checkbox with optional label and description.

Variants: 24

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Description | text |
| Show description | boolean (off) |
| Size | sm · md |
| Checked | False · True · Indeterminate |
| State | Default · Hover · Focused · Disabled |

**Do**

- Use for multiple independent choices.
- Use Indeterminate for a partially selected group.
- Turn on Description only when the label needs explaining.

**Forbidden**

- Never use a checkbox for a setting that applies instantly — use Toggle.
- Never write negative labels (“Don’t send emails”).
- Never nest checkboxes more than one level.

## Radio

Radio button for groups of mutually exclusive options.

Variants: 16

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Description | text |
| Show description | boolean (off) |
| Size | sm · md |
| Checked | False · True |
| State | Default · Hover · Focused · Disabled |

**Do**

- Use for one choice from 2–5 visible options.
- Preselect a sensible default when there is one.

**Forbidden**

- Never use a single radio on its own — use Checkbox.
- Never use radios for more than about five options — use Select.
