# Checkbox & Radio

## Checkbox

Checkbox with optional label and description.

Variants: 24

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Description | text |
| Show description | boolean (off) |
| Size | sm · md |
| Checked | False · True · Indeterminate |
| State | Default · Hover · Focused · Disabled |

**Do**

- Use for multiple independent choices.
- Use Indeterminate for a partially selected group.
- Turn on Description only when the label needs explaining.

**Don’t**

- Don’t use for instant on/off — use Toggle.
- Don’t write negative labels.
- Don’t nest more than one level.
