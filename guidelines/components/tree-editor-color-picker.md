Variants: 1

**Do**

- Use for files and categories.
- Show expand and collapse chevrons.
- Highlight the selected item.

**Forbidden**

- Never nest deeper than four levels.
- Never use a tree for flat lists.
- Never load a huge tree at once — load children on expand.
