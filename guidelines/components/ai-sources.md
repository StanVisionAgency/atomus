# AI: Sources and citations

## Sources

The numbered list of sources behind an AI answer: a "3 sources" disclosure with stacked site icons, opening to cards with the number, title, site and the passage the answer used. Numbers match the Inline citations in the text. Part of the Agent kit.

Figma: component set `Sources` on the 🤖 Agent kit page of Atomus 4.0 (node `25547:925`), connected to React with Code Connect. Rows: `Source item` (node `25547:794`); citation chip: `Inline citation` (node `25547:946`). React props use the same names as the Figma properties below.

| Property | Type / options |
|---|---|
| Sources | list (title, url, domain, snippet, icon) |
| Label | text ("N sources") |
| Style | Collapsible · List |
| Expanded | boolean |

**Use for**

- Under every answer that relies on retrieved documents, web pages or files.
- A side panel listing everything a research agent read (`variant="list"`).

**Not for**

- Links the person should act on: put them in the answer as normal links.

**Accessibility**

- The disclosure is a button with `aria-expanded`; the list is an ordered list, so numbers are announced.
- Each link says "(source 2, opens in a new tab)" to screen readers.

**Do**

- Keep the order of first citation: source 1 is [1] in the text.
- Show the passage the answer used, not the page's meta description.

**Forbidden**

- Never list sources the answer didn't use.
- Never invent or guess a URL — leave `url` empty when there is no link.

## Inline citation

A small numbered chip right after a claim. Hover or focus shows a preview card (site, title, passage); the chip links to the source. The chip tints with `bg-ai-subtle` and `border-ai` on hover and focus.

| Property | Type / options |
|---|---|
| Number | number |
| Source | Source item |

**Accessibility**

- The chip is a link named "Source 2: Title (opens in a new tab)", described by the preview card (`role="tooltip"`).
- The preview opens on focus as well as hover; Esc hides it.

**Do**

- Place the chip right after the sentence or clause it supports, before the full stop of the next one.
- Use one chip per source; repeat the number when a source supports several claims.

**Forbidden**

- Never put interactive content in the preview card.
- Never cite with colour or superscript alone — always show the number.
