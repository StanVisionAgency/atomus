# AI: Tool call

## Tool call

One function call by the agent: a plain-language title, the function name in monospace, a status pill, the run time, and a disclosure with the input and output as formatted code. Part of the Agent kit.

Figma: planned component. The properties below are the Figma properties to come; React props already use the same names.

| Property | Type / options |
|---|---|
| Title | text |
| Tool name | text |
| Status | Pending · Running · Success · Error |
| Duration | number (ms) |
| Input | code |
| Output | code |
| Expanded | boolean |
| Icon | instance swap (integration logo) |

**Status**

- **Pending** — queued or waiting; clock icon, gray pill.
- **Running** — spinner, `bg-ai-subtle` pill, the icon tile tints.
- **Success** — check, success pill ("Done"), duration.
- **Error** — alert icon, error pill ("Failed"), error border; the error message replaces the output.

**Use for**

- Showing what an agent did with your systems: searches, API calls, file reads, MCP tools.
- Debug views where people need the exact input and output.

**Not for**

- Actions that need permission first: use Approval, then show the Tool call.
- The model's thinking: use Reasoning.

**Accessibility**

- The header is a button with `aria-expanded`; status pill text changes are announced politely.
- Status is a word plus an icon, never colour alone.
- Code blocks are focusable and named ("search_docs input") so keyboard users can scroll them.

**Do**

- Write the title as what happened ("Searched the docs"), and keep the function name as a secondary label.
- Collapse calls by default; open the one that failed.
- Give an error a cause and a next step ("Reconnect Linear and try again").

**Forbidden**

- Never show secrets, tokens or personal data in the input or output — redact them first.
- Never hide a failed tool call; keep it in the thread.
