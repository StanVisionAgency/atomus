# Badge

## Badge

Status label. Light for tables and lists, Solid for emphasis. Optional dot, icon or close.

Variants: 30

| Property | Type / options |
|---|---|
| Label | text |
| Dot | boolean (off) |
| Leading icon | boolean (off) |
| Leading icon swap | instance swap (icon) |
| Close | boolean (off) |
| Size | sm · md · lg |
| Style | Light · Solid |
| Color | Gray · Brand · Error · Warning · Success |

**Do**

- Pick the colour by meaning: Success, Warning, Error, Brand (info), Gray (neutral).
- Keep labels to one or two words.
- Use Tag, not Badge, for values the user can remove.

**Forbidden**

- Never use a badge as a button or link.
- Never rely on colour alone — the word carries the meaning.
- Never place more than three badges together.

## Tag

Removable filter / selection chip.

Variants: 3

| Property | Type / options |
|---|---|
| Label | text |
| Leading icon | boolean (off) |
| Leading icon swap | instance swap (icon) |
| Close | boolean (on) |
| Size | sm · md · lg |

**Do**

- Use for user-entered or filterable values: filters, skills, recipients.
- Give removable tags a close button (`onRemove` in code).

**Forbidden**

- Never use Tag for status — use Badge.
- Never colour tags by status.
