# Toggle

## Toggle

On/off switch for settings that apply immediately.

Variants: 32

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Description | text |
| Show description | boolean (off) |
| Shape | Pill · Square |
| Size | sm · md |
| Checked | False · True |
| State | Default · Hover · Focused · Disabled |

**Do**

- Use for settings that apply immediately.
- Write the label as the setting (“Email notifications”).
- Use one shape across the product.

**Forbidden**

- Never use a toggle in a form that needs Save — use Checkbox.
- Never use a toggle for more than two states.
- Never hide the label.
