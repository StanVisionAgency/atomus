# Toggle

## Toggle

On/off switch for settings that apply immediately.

Variants: 32

| Property | Type / options |
|---|---|
| Label | text |
| Show label | boolean (on) |
| Description | text |
| Show description | boolean (off) |
| Shape | Pill · Square |
| Size | sm · md |
| Checked | False · True |
| State | Default · Hover · Focused · Disabled |

**Do**

- Use for settings that apply immediately.
- Write the label as the setting.
- Use Square shape across the product.

**Don’t**

- Don’t use in forms that need Save.
- Don’t use for more than two states.
- Don’t hide the label.
