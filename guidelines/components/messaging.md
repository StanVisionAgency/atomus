# Messaging

## Message bubble

Chat message: Received or Sent; text or file.

Variants: 4

| Property | Type / options |
|---|---|
| Name | text |
| Time | text |
| Message | text |
| Direction | Received · Sent |
| Type | Text · File |

**Do**

- Show sender, time and read state.
- Group consecutive messages.
- Use the brand bubble for the current user.

**Don’t**

- Don’t put long documents in a bubble.
- Don’t mix alignments for one sender.
- Don’t remove timestamps.
