# Messaging

## Message bubble

Chat message: Received or Sent; text or file.

Variants: 4

| Property | Type / options |
|---|---|
| Name | text |
| Time | text |
| Message | text |
| Direction | Received · Sent |
| Type | Text · File |

**Do**

- Show sender, time and read state.
- Group consecutive messages from one sender.
- Use the brand bubble for the current user.

**Forbidden**

- Never put long documents in a bubble — attach a file.
- Never mix alignments for one sender.
- Never remove timestamps.
