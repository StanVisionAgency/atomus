# Progress & loading

## Step

Single step for Progress steps.

Variants: 6

| Property | Type / options |
|---|---|
| Title | text |
| Supporting text | text |
| Show supporting | boolean (on) |
| Orientation | Horizontal · Vertical |
| Status | Complete · Current · Upcoming |

## Progress steps

Multi-step flow indicator.

Variants: 2

| Property | Type / options |
|---|---|
| Orientation | Horizontal · Vertical |

**Do**

- Use for flows of 3–7 steps and show completed, current and upcoming states.

**Forbidden**

- Never use steps to move between unrelated pages — use Tabs.

## Progress bar

Linear progress.

Variants: 3

| Property | Type / options |
|---|---|
| Label | None · Right · Bottom |

**Do**

- Show the percentage when progress is known.
- Use Loading indicator when it is not.
- Label what is progressing.

**Forbidden**

- Never use a progress bar for steps — use Progress steps.
- Never animate backwards.
- Never show several bars for one task.

## Progress circle

Circular progress.

Variants: 3

| Property | Type / options |
|---|---|
| Size | sm · md · lg |

## Loading indicator

Spinner for page or section loading.

Variants: 2

| Property | Type / options |
|---|---|
| Show label | boolean (on) |
| Size | sm · md |

**Do**

- Use for short waits where the layout is unknown.

**Forbidden**

- Never block a whole page with a spinner when a skeleton fits.

## Skeleton

Loading placeholders.

Variants: 3

| Property | Type / options |
|---|---|
| Type | Text · Avatar + text · Card |

**Do**

- Match the skeleton to the layout that will load.

**Forbidden**

- Never leave a skeleton for more than a few seconds without a message.

### `ProgressBar`

`import { ProgressBar } from '@stanvision/atomus-react';` — source: `react/src/components/ProgressBar.tsx`

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | **required** | 0–100 |
| `labelPosition` | `'none' \| 'right' \| 'bottom'` | `'right'` | Figma: Label — where the percentage sits |
| `label` | `string` | `'Progress'` | Accessible name, e.g. "Storage used" |

Also accepts every native `<div>` attribute (`id`, `role`, `onClick` …).

**Not in React yet:** Progress circle, Progress steps, Loading indicator and Skeleton are Figma-only. For a spinner inside a button use `<Button loading>`.
