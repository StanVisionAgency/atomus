## Progress bar

Linear progress.

Variants: 3

| Property | Type / options |
|---|---|
| Label | None · Right · Bottom |

**Do**

- Show percent when known.
- Use Loading indicator when not.
- Label what is progressing.

**Don’t**

- Don’t use for steps.
- Don’t animate backwards.
- Don’t show several bars for one task.
