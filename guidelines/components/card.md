# Card

## Card

Container for product and marketing layouts. Content is a slot. Styles: Outlined, Elevated, Filled. Padding md (16) / lg (24).

Variants: 6

| Property | Type / options |
|---|---|
| Content | slot (any content) |
| Title | text |
| Supporting text | text |
| Header | boolean (on) |
| Header action | boolean (on) |
| Footer | boolean (off) |
| Style | Outlined · Elevated · Filled |
| Padding | md · lg |

**Do**

- Put any content into the Content slot.
- Use the Header and Footer booleans instead of building your own.
- Use Outlined on white backgrounds and Filled on grey ones.

**Forbidden**

- Never nest cards inside cards.
- Never add shadows by hand — pick the Elevated style.
- Never detach to change padding — use the Padding variant.

## Card header

Header for cards, tables and settings sections: title, badge, supporting text and actions.

Variants: 3

| Property | Type / options |
|---|---|
| Title | text |
| Badge | boolean (on) |
| Actions | boolean (on) |
| Type | Default · Avatar · Icon |
