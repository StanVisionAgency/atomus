# Tooltip & Popover

## Tooltip

Dark tooltip; arrow None, Top, Bottom, Left, Right.

Variants: 10

| Property | Type / options |
|---|---|
| Text | text |
| Supporting text | False · True |
| Arrow | None · Top · Bottom · Left · Right |

**Do**

- Use for short hints on icons and truncated text.
- Keep it to one sentence.
- Point the arrow at the trigger.

**Don’t**

- Don’t put links or actions in tooltips.
- Don’t explain disabled buttons only by tooltip.
- Don’t repeat the visible label.
