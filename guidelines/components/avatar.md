# Avatar

## Avatar

Avatar 24–64px. Shape: Circle or Rounded. Type: Image (pick a face via the Photo property), Initials, Icon. Optional status dot.

Variants: 36

| Property | Type / options |
|---|---|
| Status | boolean (off) |
| Initials | text |
| Icon swap | instance swap (icon) |
| Size | xs · sm · md · lg · xl · 2xl |
| Type | Image · Initials · Icon |
| Shape | Circle · Rounded |

**Do**

- Use a photo when you have one; fall back to initials, then an icon.
- Always pass the person's name so the avatar has an accessible name and tooltip.
- Show the status dot only for live presence (online, away, offline).

**Forbidden**

- Never stretch or crop photos by hand — size comes from the Size variant.
- Never mix Circle and Rounded shapes in one list.
- Never use an avatar as decoration without a name nearby.
