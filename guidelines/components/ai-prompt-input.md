# AI: Prompt input

## Prompt input

The composer of an AI chat or agent panel: an auto-growing text area, attachment chips, a toolbar slot for the Model selector and tool toggles, and one button that switches between Send and Stop. Typing `/` or `@` opens a command or mention menu. Part of the Agent kit.

Figma: planned component. The properties below are the Figma properties to come; React props already use the same names.

| Property | Type / options |
|---|---|
| Text | text |
| Placeholder | text |
| Size | md · lg |
| State | Ready · Submitted · Streaming · Error · Disabled |
| Attachments | slot (attachment chips) |
| Attach button | boolean (on) |
| Toolbar slot | slot (Model selector, toggles) |
| Actions slot | slot (Context meter, voice) |
| Command menu | boolean (off) |
| Disclaimer | text |

**Anatomy**

1. Container: `bg-primary`, `border-primary`, radius 2xl (3xl at lg). When focused, the border becomes `--gradient-ai` with a `bg-ai-subtle` glow.
2. Attachment chips: file icon or thumbnail, name, size or upload state, remove button.
3. Text area: grows from `minRows` (1) to `maxRows` (8), then scrolls.
4. Bottom bar: Attach button and Toolbar slot on the left; Actions slot and Send / Stop on the right.
5. Send / Stop: brand-solid arrow while ready; `fg-contrast` square while the agent works.
6. Command menu: a listbox above the input, filtered by what follows `/` or `@`.
7. Disclaimer: one centred line under the input.

**Use for**

- The main input of a chat, copilot side panel or agent workspace.
- Follow-up questions under an AI answer inside a card or drawer.

**Not for**

- Search fields: use Input with a search icon.
- Long-form writing without an AI reply: use a textarea.
- Forms with several fields: use Input, Select and the other form components.

**Keyboard**

- Enter sends; Shift+Enter adds a line. Enter never sends while the agent is working, and never during IME composition.
- In the command menu: ↑ ↓ move, Enter or Tab inserts, Esc closes.
- The Stop button is a normal button: Tab to it and press Enter or Space.

**Accessibility**

- The text area has a visually hidden label (`label`, default "Message"); the placeholder is only a hint.
- Send and Stop have accessible names (`submitLabel`, `stopLabel`) and change name with the state.
- The command menu uses `aria-activedescendant`, so focus stays in the text area; a polite live region says how many suggestions there are.
- "Generating response" is announced when the state turns busy.
- The disclaimer is linked with `aria-describedby`.

**Do**

- Keep one Prompt input per conversation, docked at the bottom of the thread.
- Put the Model selector in the Toolbar slot and the Context meter in the Actions slot.
- Show Stop while the agent works and keep the text area editable, so people can draft the next message.
- Block Send while a file is still uploading; show the upload state on its chip.
- Add a one-line disclaimer when answers can be wrong.

**Forbidden**

- Never disable the text area while streaming — only Send is blocked.
- Never use the placeholder as the only label.
- Never put more than one primary action in the bar: Send is the primary action.
- Never move focus out of the text area when the reply arrives.
- Never send on Enter while a command menu is open — Enter inserts the highlighted item.
