## Bar chart

Grouped bar chart (12 months, 2 series).

Variants: 1

**Do**

- Start the value axis at zero.
- Use the brand series for the key metric and grey for comparison.
- Add a legend when there is more than one series.

**Forbidden**

- Never use more than four series.
- Never use 3D or gradients.
- Never hide axis labels.

## Line chart

Line chart (12 months, 2 series).

Variants: 1

**Do**

- Use for trends over continuous time.
- Label axes with units.

**Forbidden**

- Never draw categories as a line — use a bar chart.

## Pie chart

Pie and donut chart, sizes 160/200/240. Segment colours follow the Brand collection.

Variants: 6

| Property | Type / options |
|---|---|
| Type | Pie · Donut |
| Size | sm · md · lg |

**Do**

- Use for parts of a whole, with five slices or fewer.

**Forbidden**

- Never compare values across several pies — use a bar chart.
