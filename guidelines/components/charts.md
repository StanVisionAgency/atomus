## Bar chart

Grouped bar chart (12 months, 2 series).

Variants: 1

**Do**

- Start the value axis at zero.
- Use the brand series for the key metric, grey for comparison.
- Add a legend for more than one series.

**Don’t**

- Don’t use more than four series.
- Don’t use 3D or gradients.
- Don’t hide axis labels.
