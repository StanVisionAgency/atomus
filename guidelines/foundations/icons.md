# Icons
- **UI icons**: 88 components named `icon/<font-awesome-name>` (e.g. `icon/arrow-right`, `icon/magnifying-glass`). 24px frame; colour from Foreground tokens. Swap via the icon property of Button, Input, Badge, Menu item…
- Because names match Font Awesome, a file can switch to Font Awesome Pro with **Swap library**.
- Sizes: `icon-xs 12 · sm 16 · md 20 · lg 24 · xl 32`.
- Other sets: Icon brand (44 logos), Icon payment (24), Icon flag (18), Icon file type (12 types × 2 sizes), Icon folder, Icon integration (16 app tiles), Star rating, Featured icon.
- Never mix icon families; never use an icon without a label or tooltip for actions.
