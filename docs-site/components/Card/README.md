# Card

A bordered container that groups related content and actions.

## Provide

- `title`, optional `description` and `actions` (top right).
- `children` — the body; `footer` — buttons aligned right.
- `padding` — `md` 24px (product) or `lg` 32px (web sections).

## Don't

- Don't nest cards inside cards; use dividers or a bg-secondary panel instead.
- Don't add a coloured left border to signal status — use Alert or Badge.
